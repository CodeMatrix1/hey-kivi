# Positioning

Hey Kivi is a personal workspace assistant that remembers what you have said across dictations and chat, then helps you find past notes, polish them for meetings, and answer questions grounded in your own history.

Unlike a generic chatbot, Kivi separates durable semantic memory (Hindsight) from searchable dictation artifacts (SQLite FTS) and explicit spelling preferences (lexical mappings). Every turn returns an inspectable decision trace showing why Kivi answered, abstained, or retrieved a note.

Golden Goose demo: ~500 synthetic transcripts, reproducible evals, and a baseline snapshot for fast review.
